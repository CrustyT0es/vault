# Vault is now Wefty

Vault was renamed Wefty, and the app moved to https://wefty.org/. Opening https://crustyt0es.github.io/vault/ in a browser takes you there,
with the same notes; a device that's signed in moves its sign-in over with one tap.

This repo still holds the full app, kept up to date with every Wefty release: Wefty on the PC gets its updates from
here, and home-screen apps installed from the old address still open it. Made by `python -m vault.publish`; don't
edit it here.
